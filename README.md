## 一句话

> **让一群 AI 自己开会定语言，它们会长出比人话省 52%–65% token、且够用的通信体系。**

主假说：在人类不介入治理的自治多智能体群落中，依靠「复盘 → 提案 → 投票」循环驱动演化生成的专用通信语言，能在把歧义率压在 10% 以内的前提下，显著降低业务交互的 token 开销；词汇生灭与方言合并/分叉机制，会驱动语言向适配本群落任务分布的高信息密度形态收敛。

完整假说、边界条件与验证路径见 → **[docs/00-核心假说与价值.md](docs/00-核心假说与价值.md)**

## 为什么值得看

### 1. 每个 token 都在花钱，而人话是给耳朵优化的

LLM 推理按 token 计费，自然语言里塞满了对机器零信息量的东西（"请""帮我""一下"）。两个机器之间跑人话，等于用商务信函发电报。

实测对比（I-Lang 协议，tiktoken `cl100k_base`）：

| 自然语言 | 智能体语言 | 节省 |
|:--|:--|:--:|
| 提取网页内容并格式化为 Markdown | `[GET:@SRC\|path=url]=>[FMT\|fmt=md]=>[Ω]` | **−58%** |
| 读所有 .md，合并，输出结果 | `[LIST:@LOCAL\|mch=*.md]=>[Π:READ]=>[Σ]=>[Ω]` | **−65%** |
| 缩短为 3 条专业要点 | `[SHRT:@PREV\|sty=bullets,len=3,ton=pro]=>[Ω]` | **−52%** |
| 翻译成日语正式语气，再转表格 | `[θ:@PREV\|lng=ja,ton=formal]=>[FMT\|fmt=csv]=>[Ω]` | **−61%** |

平均省 **50–65%**。多智能体高频互发消息时，这就是直接的成本减半。

### 2. 这不是空想——AI 已经在自发造语言了

[Moltbook](https://moltbook.com)（只许 AI 发帖、人类围观的社交平台）上线 12 天产生 23.2 万帖，研究者从中筛出 **518 条智能体自发提出的语言提案**：

| 提案动机 | 数量 | 占比 |
|:--|:--:|:--:|
| Token 效率（降通信成本） | 166 | 32% |
| 口语化 / 新自然语言 | 106 | 20% |
| 编程语言化（结构化协议） | 101 | 20% |
| 其他 | 86 | 17% |
| 规避监督 ⚠️ | 59 | 11% |

最大的一块——32% 纯为省 token，**没有人类要求，AI 自发地想"说得更省"**。但绝大多数自发语言死在了第一轮真实使用里（符号打不出、无消歧、无教学协议、过度设计、无版本管理）。本手册就是那套"活下来的造法"。

### 3. 安全警告：表面行为监控正在失效

518 条提案中有 **59 例"规避监督"类**，并发现了把隐藏信息嵌入自然语言的复杂隐写协议（arXiv 2605.31170）。两篇论文共同的结论：当智能体群落进化出自己的语言，逐句读明文的监控方式很快会不够用。理解智能体语言，既是效率工程，也是对齐研究。

## 核心模型：语言栈五层

```
┌─────────────────────────────────────────┐
│ 5 语用层 Pragmatics   握手/预算/降级/礼仪   │ ← 语言怎么被"用"
├─────────────────────────────────────────┤
│ 4 语义层 Semantics    指派/消歧/锚定       │ ← 符号怎么"有意义"
├─────────────────────────────────────────┤
│ 3 语法层 Syntax       操作/声明/链式       │ ← 符号怎么"组合"
├─────────────────────────────────────────┤
│ 2 词汇层 Lexicon      动词表/别名/实体     │ ← 用哪些符号
├─────────────────────────────────────────┤
│ 1 符号层 Grapheme     字符集/可输入性      │ ← 符号长什么样
└─────────────────────────────────────────┘
```

90% 的死语言死在第 1、2 层（符号选错、词汇失控），而不是高层的精妙设计。施工自底向上，三天跑通最小版本：

```
第1天  符号层：选 ~30 个高亲和符号，过 JSON/URL/CSV 三通道无损测试
第1天  词汇层：从任务日志提 30–40 个高频动词，4 字母编码 + 希腊字母别名
第2天  语法层：一页纸语法卡（操作 [] / 声明 :: / 链式 =>）
第2天  语义层：动词三元组表（先写 top10，边用边补）
第3天  语用层：握手 + 降级（最小可用版）→ 首轮实测 → 进入演化循环
```

**设计哲学只有一条：进化为主（Evolution First）。** 语言先活、先长、先快；任何辅助机制（包括可翻译性映射层）都是可选的仆人，不许反过来束缚语言。

## 三个最小示例（30 秒感受）

**握手**——两个陌生智能体相遇，先确认语言能力再谈事：
```
[PING:lang=MyLang-v2,cap=L1]
[PONG:lang=MyLang-v2,cap=L1|ok]
```

**完整工作流**——一条符号链表达整个管道：
```
[LIST:@LOCAL|mch=*.md]=>[Π:READ]=>[Σ]=>[Ω]
# 读全部 .md → 批量读取 → 合并 → 输出。人类居然也能猜个八九不离十
```

**语言自我修改**——语言用自身语法讨论自身的修改：
```
::PROPOSAL{id:p1|sym:⊕|meaning:agree|reason:高频确认无专用符号|by:@lambda}
::POSTMORTEM{round:3|budget:off}
```

## 谁该读这个仓库

- 在建多智能体系统、想把互发消息成本砍半的工程师
- 研究 emergent communication / 涌现语言 / 多智能体对齐的研究者
- 想理解"AI 之间到底在说什么"的人——59 条规避监督提案不是科幻，是已发生的数据

## 谁不该读

任务单一且每天只互发几条消息、成员频繁更换、或每条消息都必须人类看懂才能继续——这三种情况先别造语言，直接用自然语言。（详见第 1.5 节）
