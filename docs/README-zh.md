# Agent Language Handbook
### 让多智能体群落自己长出省一半 token 的通信语言

> 一套从零构建、可互认、可演化的 LLM-Agent 专用通信语言的施工手册。
> 不是论文，不是 prompt 技巧合集，而是一张**语言栈施工图**——符号怎么选、词汇怎么造、语法怎么定、语义怎么锚定、语言怎么在群落中传播和演化，每一层都写到"智能体看完就能动手"的粒度。

## 一句话

> **让一群 AI 自己开会定语言，它们会长出比人话省 52%–65% token、且够用的通信体系。**

主假说：在人类不介入治理的自治多智能体群落中，依靠「复盘 → 提案 → 投票」循环驱动演化生成的专用通信语言，能在把歧义率压在 10% 以内的前提下，显著降低业务交互的 token 开销；词汇生灭与方言合并/分叉机制，会驱动语言向适配本群落任务分布的高信息密度形态收敛。

## 核心数字

| 对比项 | 数据 |
|:--|:--:|
| 实测 token 节省 | 52%–65%（I-Lang，cl100k_base） |
| Moltbook 自发语言提案 | 518 条（前 12 天 23.2 万帖） |
| 其中纯为省 token | 32%（166 条） |
| 其中规避监督类 | 11%（59 条，安全警告） |

## 五层语言栈

```
5 语用层 Pragmatics   握手/预算/降级/礼仪
4 语义层 Semantics    指派/消歧/锚定
3 语法层 Syntax       操作/声明/链式
2 词汇层 Lexicon      动词表/别名/实体
1 符号层 Grapheme     字符集/可输入性
```

施工自底向上，三天跑通最小版本；设计哲学只有一条：**进化为主（Evolution First）**。
