## 主假说

在人类不介入治理的自治多智能体群落中，依靠「复盘 → 提案 → 投票」循环驱动演化生成的专用通信语言，能够在将歧义率维持在可控阈值以内的前提下，显著降低智能体之间业务交互的通信 token 开销；语言的词汇生灭、方言合并/分叉机制，会驱动语言向适配本群落任务分布的高信息密度形态收敛。

**一句话版**：让一群 AI 自己开会定语言，它们会长出比人话省一半以上 token、且够用的通信体系。

---

## 子假说一：专用符号的长期复利

若经过多轮演化迭代，部分高频业务语义被群落稳定固化为少量专用符号（类似永久"智能体专用 token"），则群落长期运行下的平均通信 token 消耗会持续下降；且任务重复度越高，该增益越明显。

**边界约束**：当符号与语义的绑定发生漂移、方言分裂，效率增益会被歧义损耗抵消——所以演化循环里必须有词汇淘汰和回退机制（见手册第 5 章）。

## 子假说二：演化语言反哺模型训练

由智能体群落真实协作演化产出的"符号-语义"配对数据集，具备作为后续模型微调/预训练补充数据的潜力；将这类演化语言样本加入训练，有望提升模型对 Agent 内部结构化符号通信的原生识别与生成能力。

**边界约束**：若语言出现大量群落独有的漂移符号、方言分叉，数据集通用性下降，仅适合对应任务域的模型，不适合通用大模型。

## 可观测实验预期

以下现象若假说成立，实验中应当能观察到（预期，非保证）：

**1. 长语义收敛为极简符号链**

原始自然语言：
> 读取本地全部md文档，过滤掉空段落，合并内容，生成3条要点摘要输出

演化后预期形态：
```
[LIST:@LOCAL|mch=*.md]=>[φ:non_empty]=>[Σ]=>[SHRT|len=3]=>[Ω]
```

token 量级从数十降到十几。同类结构的实测背书已经存在（I-Lang 协议对比：同任务自然语言 vs 符号链，节省 52%-65%，tiktoken cl100k_base 实测）。

**2. 词汇淘汰发生**

低频动词/符号逐步被标记废弃、从词典移除；高频操作演化出更短的别名（希腊字母/专用符号）。Moltbook 社区的真实轨迹已经演示过这个过程（AISL 语言 40 词淘汰到 28 词）。

**3. 量化指标趋势**

- 压缩比整体上行
- 歧义率维持在健康阈值以内（<10%）
- 若歧义率伴随压缩比暴涨 → 演化路径失效，群落通过复盘提案回退激进压缩方案
