## v1.2 (2026-09-25 轮5复盘会通过，7项变更)

来源：轮4代码分析域实测（run4_report）+ 三委员独立投票（run5_vote_*，三模型家族）。

1. **+@PREV2/@PREV3 历史槽位**（3/0）— 双READ串联不丢前源；计数规则写死：按产生输出的步骤倒序，无输出步骤不占序号
2. **+多源显式规则**（2⊕+1?）— 链中≥2个READ/FIND时引用多源必须显式 src=；@PREV2本身即显式；单读链豁免
3. **VALD 驳回类型标注**（3/0）— 判定须标 忠实/偏差/编造/过度推断，供复盘统计防虚胖
4. **? 票收编** — qwen 连续两轮自发用 ? 表达弃权/有保留，立法者裁定收编：投票语境 ? = 弃权（附理由），⊕⊖? 之外无效
5. **勘误 out= 正式入卡**（qwen 提案）— v1.1 语义表已支持但语法卡漏写，规范对齐现实
6. **勘误 ∅ 正式注册**（glm 提案）— 消除规范自相矛盾（semantics FIND 用 ∅ 但语法卡禁未注册符号）
7. **澄清 FAIL×LOOP 交互**（glm 提案）— LOOP 链内 FAIL 不触发独立退避，由 max 机制接管

**否决记录：** P4 域标签 0/3 被否（deepseek 收益存疑 / glm 无问题支撑 / qwen 可能误导）——立法者提案首次被委员会压倒性否决，防虚胖机制正常。
**挂起：** 提案附实证（deepseek，1/3）、LOOP exit_cond（qwen，1/3）、@NEXT（沿用）。

## v1.1 (2026-09-25 轮2复盘会通过，8项变更)

来源：轮0互认测试（三家族共识盲区）+ 轮1实测（run1_report）+ 三委员独立投票（run2_vote_*）

1. **+[IF:cond]=>[A]** 条件分支 — 成立才执行；不成立/不可判定⇒不执行；假跳链免Ω（P1，3/0）
2. **+[LOOP|every,max]=>[A]=>[μ]** 循环 — μ 固定链尾；max缺省3；达max⇒[FAIL:max_reached]（P2，2/1，吸收qwen反对意见收紧μ位置）
3. **Σ支持 out= 直接落盘** — 等价 MERG=>WRIT 两步；槽位用 out= 非 dst=（P3，3/0，采纳glm修正）
4. **FIND/READ 分工写死** — FIND=检索关键词（whr=关键词），READ=整读全文（P4，3/0）
5. **Ω 终点规则** — ≥2步任务链必须Ω结尾，缺Ω⇒[FAIL:no_terminal]；单步消息豁免（P5，2/1，吸收deepseek反驳加豁免条款）
6. **参数速查表** — 14槽位固定清单（11原+cond/every/max，glm caveat 同步）+ len/out/dst 易混标注（P6，3/0）
7. **UTF-8 编码强制** — 全链路 UTF-8 无BOM，乱码=[FAIL:encoding]（三家族独立撞车提案，治轮1 mojibake 根因）
8. **路径别名 @ALIAS** — 握手时 ::ALIAS{短名:路径} 声明，消 Windows 绝对路径 token 黑洞（deepseek+glm 共同提案，为 high 档预算铺路）

搁置：qwen 的 @NEXT 显式链引用（1/3 不足门槛，下轮再议）
